# Семантическое версионирование и шаблонизация (Version Engine)

Модуль `SwanCore` предоставляет потокобезопасные, строго типизированные инструменты для парсинга, сравнения и динамического форматирования программных версий (Semantic Versioning 2.0.0), адаптированные под требования Swift 6 Strict Concurrency.

## ✨ Ключевые особенности
* **Декларативный шаблонизатор на регулярных выражениях**: Компонент `VersionFormatter` компилирует строковые паттерны без использования тяжеловесных лексических анализаторов. Вся логика разбора делегирована оптимизированному системному движку `NSRegularExpression`.
* **Умное вырезание опциональных блоков**: Использование квадратных скобок `[...]` в шаблонах позволяет автоматически скрывать префиксы, суффиксы и разделители (точки, дефисы, плюсы), если подлежащий компонент версии (например, патч или билд) пуст или отсутствует. Поддерживаются даже вложенные скобки (например, `[[-RI.RV]]`).
* **Интеллектуальный Lossless-парсер**: Многоступенчатый разбор строк переваривает любые форматы: от каноничного SemVer (`1.2.3-beta.2`) до плоских брендированных тегов (`v1.4rc3b12`) и развесистого системного текста (`version 2.0 (build 45)`).
* **Каскадное сравнение (`Comparable`)**: Метод сравнения последовательно оценивает компоненты от мажора до номера сборки, используя числовые веса для жизненного цикла пререлизов (`alpha < beta < rc < release`). Missing-компоненты безопасно приводятся к логическому нулю через наш оператор `~!`.
* **Интеграция с хост-системой**: Свойство `Version.application` автоматически собирает и инициализирует структуру для текущего запущенного приложения на основе его `Bundle`-метаданных.

---

## 🚀 Базовое использование (Парсинг и Сравнение)

Благодаря поддержке протокола `LosslessStringConvertible`, версии можно инициализировать и сравнивать напрямую через стандартный синтаксис Swift:

```swift
import SwanCore

// 1. Инициализация из строк различных форматов
if let v1 = Version("1.2.3-rc.1"), let v2 = Version("v1.2") {

    // 2. Каскадное сравнение (v1.2 эквивалентно 1.2.0)
    print(v1 < v2) // true (rc.1 предшествует стабильному релизу)
    print(v2 == Version(major: 1, minor: 2, patch: 0)) // true
}

// 3. Быстрый доступ к версии текущего приложения
if let appVersion = Version.application {
    print("Текущая версия приложения: \(appVersion.formatted(.medium))")
}
```

## 🛠 Динамическое форматирование (Шаблонизатор строк)

Форматирование версий управляется токенами внутри строки шаблона. Опциональные компоненты оборачиваются в квадратные скобки `[...]`. Если компонент равен `nil` или `.release` (считается пустым для `PreReleaseIdentifier`), весь блок внутри скобок полностью вырезается из итоговой строки.

### 📐 Системные пресеты:
* **`.short`** (`%MJ[.MN][.P]`): Выводит только значащие цифры релиза. `Version("1.0.0")` превратится в `"1"`.
* **`.medium`** (`v%MJ.%MN[.P][-RI][RV][+bB]`): Дефолтный брендированный стиль Сюиты. Выводит `"v1.2.3-rc1+b45"`.
* **`.semVer`** (`%MJ.%MN.%P[-RI][.RV]`): Строгое соответствие спецификации SemVer 2.0.0. Выводит `"1.2.3-rc.1"`.
* **`.long`** (`version %MJ.%MN.%P[[-RI.RV]] build %B`): Официальный инженерный лог. Демонстрирует работу вложенных скобок.

### 📦 Пример кастомных шаблонов:
```swift
let version = Version(major: 4, minor: 2, preReleaseIdentifier: .beta, preReleaseVersion: 7, build: 88)

// Пример 1: Изолированные префиксы внутри скобок
let f1 = VersionFormatter(format: "[RELEASE: [RI] (vRV)]-b%B")
print(f1.string(from: version)) // Выведет: "RELEASE: beta (v7)-b88"

// Пример 2: Кастомный разделитель, который пропадет, если билда нет
let f2 = VersionFormatter(format: "%MJ.%MN.%P[ - B]")
print(f2.string(from: version)) // Выведет: "4.2.0 - 88"

let vMinimal = Version(major: 2, minor: 0)
print(f2.string(from: vMinimal)) // Выведет: "2.0.0" (блок " - B" полностью вырезан!)
```

> 💡 **Примечание по очистке скобок:**
> Если в сложном кастомном шаблоне несколько опциональных блоков идут подряд и все они оказываются пустыми, движок в самом конце выполняет плоскую зачистку пустых остаточных артефактов вызовом `replacingOccurrences(of: "\\[\\]", with: "")`, сохраняя итоговую строку в идеальном косметическом виде.
