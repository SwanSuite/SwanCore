# Динамическая Локализация Строк (Localization Engine)

Компонент `Bundle+Localization` предоставляет расширения для типов `Bundle` и `String`, упрощающие работу с локализацией в модульных и многокомпонентных Apple-приложениях. Ключевая фича модуля — механизм `DynamicBundle`, который автоматически определяет вызывающий бандл на лету без необходимости хардкодить `Bundle(for:)`.

## ✨ Ключевые особенности
* **Контекстный бэктрейс (Dynamic Proxy)**: Свойство `Bundle.dynamic` анализирует адреса возврата потока (`Thread.callStackReturnAddresses`) и через низкоуровневый системный вызов `dladdr` вычисляет конкретный `.framework` или `.bundle`, который инициировал вызов локализации.
* **Атомарное кэширование**: Результаты поиска бинарных образов кэшируются в хэш-таблице под защитой современного и быстрого примитива синхронизации `OSAllocatedUnfairLock` (iOS 16+ / macOS 13+). Повторные вызовы занимают наносекунды.
* **Высокая скорость на горячих путях**: Стандартные методы локализации снабжены аннотацией `@inlinable` для прямой оптимизации компилятором на этапе сборки.
* **Безопасный фоллбэк**: Если контекст вызова не удалось распознать, движок прозрачно переключается на ресурсы главного бандла приложения (`Bundle.main`).

## 🚀 Использование

### 1. Стандартная локализация (Главный бандл)
Для обычного получения строк из `Localizable.strings` главного приложения используются лаконичные вычисляемые свойства расширения `String`:

```swift
import SwanCore

// Быстрый вызов для главного бандла (.main)
let text = "welcome_title".localized
```

### 2. Контекстно-зависимая локализация (Внутри фреймворков)
Если вы пишете независимый UI-компонент, дизайн-систему или саб-модуль, который должен читать строки из *своего собственного* бандла, а не из вызывающего приложения, используйте `localizedDynamic`:

```swift
// Внутри кода вашего кастомного фреймворка:
let headerText = "feature_screen_title".localizedDynamic
```
Движок автоматически найдет нужный бинарник в памяти и заберет перевод из ресурсов вашего модуля.

### 3. Расширенный вызов с параметрами
Вы можете явно переопределять целевой бандл, указывать кастомную таблицу строк (`.strings` файл) или задавать дефолтное значение на случай отсутствия ключа:

```swift
let customText = "error_network_timeout".localized(
    Bundle.dynamic, 
    value: "Произошла ошибка соединения", 
    table: "Errors"
)
```

### 4. Низкоуровневое извлечение словаря строк
Для специфических задач (например, предзагрузки, отладки или кастомного кэширования) метод `fetchLocalizableStrings()` позволяет прочитать и десериализовать весь файл локализации в память в виде стандартного словаря. Метод маркирован как `throws`, что обязывает явно обрабатывать ошибки ввода-вывода:

```swift
do {
    if let allStrings = try Bundle.main.fetchLocalizableStrings() {
        print("Загружено ключей локализации: \(allStrings.count)")
    }
} catch {
    print("Ошибка чтения файла локализации: \(error)")
}
```

## ⚠️ Важное предупреждение о производительности (Performance Warning)

**НЕ злоупотребляйте свойством `localizedDynamic` на высокочастотных путях выполнения!**

Каждое первое обращение к свойству из нового участка кода заставляет операционную систему выполнять тяжелую операцию инспекции бэктрейса потока. Несмотря на то, что последующие вызовы для этого же фреймворка мгновенно берутся из кэша через `OSAllocatedUnfairLock`, первичный сбор символов стека создает ощутимый рантайм-оверхед.

**Категорически запрещено использовать `localizedDynamic` внутри:**
* Методов конфигурации ячеек списков (`cellForRowAt:`, `collectionView(_:cellForItemAt:)`).
* Высокочастотных циклов (`for`, `while`, `forEach`).
* Методов отрисовки и разметки интерфейса (`layoutSubviews()`, `draw(_:)`).

**Рекомендуемая альтернатива для горячих путей:**
Если вам нужно вывести локализованную строку внутри скроллящегося списка, закешируйте её статически на уровне контроллера/модели при инициализации, либо передавайте целевой бандл явно, используя быстрый инлайновый метод, который вообще не трогает стек потока:

```swift
// Мгновенный вызов без оверхеда на бэктрейс:
let cellText = "list_item_title".localized(Bundle.main) 
```
