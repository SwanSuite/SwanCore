# Расширения Bundle и Метаданные Приложения

Модуль `SwanCore` предоставляет набор легковесных и оптимизированных инлайновых свойств для быстрого доступа к метаданным приложения (`Info.plist`).

## ✨ Особенности реализации
* **Высокая производительность**: Все свойства доступа к метаданным помечены аннотацией `@inlinable`, что позволяет компилятору оптимизировать вызовы на этапе сборки конечного приложения.
* **Безопасность типов**: Исключает ручную работу со строковыми ключами словаря `infoDictionary` и приведение типов `as? String`.
* **Готовность к Swift 6**: Код полностью совместим со строгим режимом многопоточности (*Strict Concurrency*).

## 🚀 Использование

### 1. Статические свойства для главного таргета (Short-hands)
Для быстрого получения данных о запущенном приложении используйте глобальные статические свойства. Если какого-то ключа не окажется в `Info.plist`, свойства безопасно вернут пустую строку `""` с помощью оператора `~!`.

```swift
import SwanCore

// Получение имени исполняемого файла
let executable = Bundle.appExecutable // "SwanKitDemo"

// Маркетинговая версия приложения (CFBundleShortVersionString)
let version = Bundle.appVersion       // "0.1.0"

// Номер текущей сборки (CFBundleVersion)
let build = Bundle.appBuild           // "42"

// Отображаемое имя приложения (с фоллбэком на базовое имя bundle)
let displayName = Bundle.appDisplayName // "SwanSuite Demo"
```

### 2. Динамические свойства инстанса Bundle
Если вам необходимо прочитать метаданные конкретного бандла (например, внутри фреймворка или плагина), используйте динамические свойства экземпляра:

```swift
let myBundle = Bundle(for: CurrentClass.self)

if let bundleVersion = myBundle.shortVersion {
    print("Версия текущего бандла: \(bundleVersion)")
}
```
