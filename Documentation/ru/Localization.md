# Подсистема локализации

Легковесная и выразительная инфраструктура расширения `Bundle` и `String` для упрощения процессов локализации интерфейсов. Компонент предоставляет чистый синтаксис поверх нативных методов Foundation с нулевыми накладными расходами на производительность.

---

## Ключевые компоненты и API

### 1. Расширения Bundle для работы с ресурсами
* **`localized(_:value:table:)`**: Лаконичный аналог нативного системного метода `localizedString(forKey:...)`.
* **`localized(_:value:table:locale:with:)`**: Поиск строк с поддержкой правил форматирования системных локалей (`Locale`) и потоковой передачи аргументов `CVarArg`.
* **`fetchLocalizableStrings()`**: Синхронно парсит и извлекает сырое содержимое файла `Localizable.strings` в словарь. Предоставляет удобное представление всей карты переводов (позволяет исследовать состав бандлов, включая системные фреймворки вроде UIKit, для поиска неизвестных или скрытых ключей).
* **`Bundle.UIKit`**: Статическая константа, ссылающаяся на системный контейнер ресурсов `UIKit` на основе рефлексии метаданных класса `UIApplication`. Доступно на платформах `iOS` и `tvOS`.

### 2. Выразительный синтаксис для String
* **`localized`**: Свойство-справочник, запрашивающее ресурсы из главного бандла приложения (`Bundle.main`).
* **`localized(_:value:table:)`**: Точечный вызов строки относительно переданного контекста бандла.

## Решения и примеры интеграции

### 1. Явная локализация в субмодулях
Явное объявление и передача целевого бандла гарантирует безопасность на этапе компиляции, строгое разделение зависимостей и максимальное быстродействие.

```swift
public enum FeatureStrings {
    // Стандартное явное определение бандла для субмодуля
    private static let moduleBundle = Bundle(for: CurrentModuleMarker.self)

    public static var moduleTitle: String {
        "feature_dashboard_title".localized(moduleBundle)
    }
    
    public static func welcomeAlert(user: String) -> String {
        "welcome_user_format".localized(moduleBundle, with: user)
    }
}
```

### 2. Использование официальных системных переводов (UIKit)
Вместо дублирования кастомных строк для стандартных кнопок операционной системы, вы можете использовать официальные локализации Apple напрямую через привязку к бандлу `.UIKit`.

```swift
// Автоматически извлекает официальный перевод ОС для кнопок "Отмена" или "Готово" под язык устройства
let systemCancelLabel = "Cancel".localized(.UIKit)
let systemDoneLabel = "Done".localized(.UIKit)
```

### 3. Исследование локализации системных фреймворков
Через метод `fetchLocalizableStrings()` в связке с `.UIKit` можно быстро выгрузить и посмотреть системные переводы интерфейса для поиска нужных ключей во время отладки.

```swift
#if os(iOS) || os(tvOS)
if let nativeTranslations = try? Bundle.UIKit.fetchLocalizableStrings() {
    for (key, value) in nativeTranslations.prefix(10) {
        print("Ключ UIKit: \(key) -> [\(value)]")
    }
}
#endif
```
