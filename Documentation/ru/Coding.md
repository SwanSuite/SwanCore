# Модуль расширений сериализации SwanCore (JSON Codable Helpers)

Компонент предоставляет вспомогательные инструменты, расширения и протоколы для оптимизации процессов сериализации и десериализации данных в экосистеме Swift, расширяя стандартные механизмы `JSONEncoder` и `JSONDecoder`. Инструмент автоматизирует вывод типов и обеспечивает динамическую двунаправленную трансформацию нотаций кодирования ключей в реальном времени.

## Архитектура и основные компоненты

Инструментарий включает три взаимосвязанных слоя:
1. **Интерфейс вывода типов (Type Inference API)**: Расширения для `JSONDecoder`, `Decodable` и `Data`, устраняющие необходимость явной передачи метатипов на стороне вызова, если тип однозначно определяется компилятором.
2. **Декларативное конфигурирование (Fluent API)**: Методы настройки кодеров и декодеров на базе шаблона проектирования Builder, позволяющие инициализировать и модифицировать параметры сериализации через цепочки вызовов.
3. **Динамический маппинг и трансформация ключей**: Механизм перехвата процесса кодирования на базе протокола `CustomizableCodingKeyMapping` и специализированных структур `CamelKey` / `ScreamingSnakeKey` для автоматического перевода строк между нотациями.

---

## Протокол CustomizableCodingKeyMapping

Протокол наследуется от `CodingKey` и `Sendable`, гарантируя потокобезопасность при использовании в асинхронных контекстах Swift 6 Strict Concurrency. 

```swift
public protocol CustomizableCodingKeyMapping: CodingKey, Sendable {
    var mapped: CodingKey { get }
}
```

Реализуя свойство `mapped`, разработчик может определить явное правило подмены для конкретного ключа. Если ключ удовлетворяет данному протоколу, кастомная стратегия кодирования/декодирования автоматически выполнит перенаправление. По умолчанию предоставляется тождественное отображение (`self`).

## Встроенные стратегии трансформации регистров

Компонент предоставляет две готовые расширенные стратегии, которые комбинируют автоматическое изменение стиля имен со сквозной поддержкой динамического маппинга:

### 1. Стратегия `convertFromSnakeCaseExtended`
* **Область применения**: `JSONDecoder.KeyDecodingStrategy`.
* **Принцип работы**: Использует структуру `CamelKey` для автоматического преобразования ключей из формата `snake_case` в `camelCase`. 
* **Логика**: Если ключ поддерживает `CustomizableCodingKeyMapping`, применяется индивидуальное правило `mapped`, иначе имя приводится к `camelCase` через расширение строки.

### 2. Стратегия `convertToScreamingSnakeCase`
* **Область применения**: `JSONEncoder.KeyEncodingStrategy`.
* **Принцип работы**: Использует структуру `ScreamingSnakeKey` для автоматического преобразования свойств формата `camelCase` в конфигурационные ключи верхнего регистра `SCREAMING_SNAKE_CASE`.
* **Изоляция коллекций**: Метод `init(intValue:)` защищает индексы массивов от ошибочной конвертации: индекс транслируется в строку для стабильности кодера, но свойство `intValue` принудительно возвращает `nil`.

## Примеры использования

### 1. Лаконичное декодирование на основе вывода типов
```swift
// Традиционный подход Foundation:
let user = try JSONDecoder().decode(User.self, from: rawData)

// Подход SwanCore (тип выводится автоматически из контекста):
let user: User = try rawData.decode()
let profile: Profile = try JSONDecoder().decode(payloadData)
```

### 2. Конфигурация декодера через Fluent API и Snake Case
```swift
let decoder = JSONDecoder()
    .keyDecodingStrategy(.convertFromSnakeCaseExtended)
    .dateDecodingStrategy(.iso8601)

let session: Session = try decoder.decode(networkData)
```

### 3. Сериализация в SCREAMING_SNAKE_CASE
```swift
let encoder = JSONEncoder(.convertToScreamingSnakeCase)
    .dateEncodingStrategy(.millisecondsSince1970)

// Инвертированный вызов кодирования непосредственно на экземпляре модели
let payload: Data = try serverConfig.encode(encoder: encoder)
```

## Утилиты трансформации строк (String Case Converting)

Расширение над типом `String` выполняет атомарные низкоуровневые преобразования без задействования тяжелых системных локалей:
* `upperFirst()` — переводит в верхний регистр только первый символ строки, сохраняя структуру последующих данных.
* `pascalCasedSnake` — выполняет покомпонентный разбор `snake_case` и собирает строку в формате `PascalCase`.
* `camelCasedSnake` — трансформирует `snake_case` в `camelCase`.
* `camelCaseTo_SCREAMING_SNAKE` — разбирает `camelCase` с помощью регулярных выражений, внедряя символы подчеркивания перед границами заглавных букв и чисел, с последующим приведением всей строки к верхнему регистру.
