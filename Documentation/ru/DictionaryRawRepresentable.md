# Расширения словарей и RawRepresentable трансформации

Модуль `SwanCore` предоставляет функциональные расширения для стандартного типа `Dictionary`, упрощающие трансформацию хэш-таблиц, маппинг ключей/значений и взаимную конвертацию между доменными перечислениями (`RawRepresentable`) и примитивными типами данных.

## Системные особенности

* **Функциональная трансформация**: Методы `mapToDictionary` и `compactMapToDictionary` позволяют преобразовывать структуру целиком в один вызов, используя оптимизированные нативные конструкторы Swift.
* **Изолированный маппинг ключей**: Расширения `mapKeys` и `compactMapKeys` меняют типы и регистры ключей без повторного выделения памяти под полезную нагрузку значений.
* **Разрешение представлений**: Набор перегрузок `resolveRepresentation` обрабатывает матрицы данных, переводя словари из объектных перечислений в сырые структуры для сериализации (и обратно).
* **Детерминированная очистка**: При конвертации сырых данных в строго типизированные перечисления последовательность `compactMap` отсекает элементы, которые не прошли инициализацию.
* **Оптимизация компиляции**: Все методы помечены аннотацией `@inlinable` для инлайнинга кода компилятором на этапе оптимизации сборки.
* **Стриминг с контролируемой аллокацией**: Метод `lazyCompactMapToDictionary` выполняет трансформацию без выделения промежуточных массивов, передавая ленивую последовательность в результирующую хэш-таблицу.

## Функциональный маппинг

Данные расширения заменяют императивные циклы и промежуточные мутабельные словари при базовых трансформациях данных:

```swift
import SwanCore

let source = ["one": 1, "skip_me": 2, "three": 3]

// 1. Маппинг словаря с фильтрацией nil-значений
let transformed: [String: String] = source.compactMapToDictionary { key, value in
    guard key != "skip_me" else { return nil }
    return (key.uppercased(), String(value * 10))
}
// Результат: ["ONE": "10", "THREE": "30"]

// 2. Трансформация только ключей словаря
let dictWithUpperKeys = source.mapKeys { \$0.uppercased() }
// Result: ["ONE": 1, "SKIP_ME": 2, "THREE": 3]
```

## Ленивая трансформация данных

Для критичных к производительности участков кода метод `lazyCompactMapToDictionary` минимизирует выделение памяти в куче за счет стриминга ленивой последовательности (`lazy.compactMap`) напрямую в результирующую хэш-таблицу с заранее зарезервированной емкостью.

```swift
let heavySource: [String: Int] = /* Большой словарь данных */

let efficientResult: [String: String] = heavySource.lazyCompactMapToDictionary { key, value in
    guard value % 2 == 0 else { return nil }
    return (key.camelCasedSnake, "Value_\(value)")
}
```

## Управление перечислениями через resolveRepresentation

Система `resolveRepresentation` автоматически выводит целевые типы из контекста вызова и выполняет конвертацию представлений.

### 1. Конвертация из перечислений в сырые типы (Сериализация)
Переводит строгие доменные перечисления в сырые строки или числа, готовые для кодирования в слоях сериализации данных:

```swift
enum ResponseKey: String { case id = "id_field", status = "status_field" }
enum UserStatus: Int { case pending = 0, active = 1 }

let domainDict: [ResponseKey: UserStatus] = [.id: .active]

// Преобразование: [EnumKey: EnumValue] -> [String: Int]
let apiPayload: [String: Int] = domainDict.resolveRepresentation()
```

### 2. Реконструкция из сырых типов в перечисления (Парсинг DTO)
Восстанавливает доменные модели из примитивных типов с гарантией безопасности: невалидные значения или неизвестные ключи отсекаются без прерывания выполнения программы:

```swift
let rawInput: [String: Int] = ["id_field": 1, "status_field": 99] // 99 — невалидный статус

// Преобразование: [String: Int] -> [ResponseKey: UserStatus]
let cleanDomainDict: [ResponseKey: UserStatus] = rawInput.resolveRepresentation()
// Результат: cleanDomainDict[.id] == .active, cleanDomainDict[.status] == nil
```

### 3. Глубокое развертывание опционалов
Специализированные перегрузки удаляют опциональные обертки, одновременно приводя ключи и значения к целевым типам в рамках одного прохода:

```swift
let rawWithNils: [ResponseKey: String?] = [.id: "123", .status: nil]

// Преобразование: [EnumKey: Value?] -> [String: Value]
let cleanPayload: [String: String] = rawWithNils.resolveRepresentation()
// Результат: cleanPayload.count == 1 (узел со значением nil удален)
```

## Анализ производительности и компиляции

Интеграция системы `resolveRepresentation` в архитектурные слои требует учета накладных расходов на этапе сборки и в рантайме:

* **Накладные расходы компиляции**: Под капотом развернута многоуровневая дженерик-матрица перегрузок. Избыточное нагромождение вызовов `resolveRepresentation` увеличивает время сборки проекта из-за высокой вычислительной нагрузки на механизм вывода типов (Type Inference).
* **Накладные расходы рантайма**: Метод полностью перестраивает хэш-таблицу в памяти с выделением новых нод и бакетов. Избегайте вызовов разрешения представлений внутри высокочастотных циклов или на путях UI-рендеринга. Выполняйте конвертацию в слоях парсинга DTO на фоновых потоках.
