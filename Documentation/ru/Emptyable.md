# Протокол Emptyable и Операторы Безопасного Развертывания

Компонент `Emptyable` предоставляет унифицированный интерфейс для типов данных, имеющих четко определенное «пустое» состояние, а также вводит безопасные альтернативы операторам принудительного развертывания опционалов.

## ✨ Ключевые особенности
* **Безопасность вместо крашей**: Постфиксный оператор `~!` заменяет системный forced unwrap `!`, возвращая дефолтное пустое значение вместо падения приложения.
* **Строгая многопоточность**: Протокол наследуется от `Sendable`, гарантируя потокобезопасный перенос инстансов через границы конкурентных задач в Swift 6.
* **Широкая поддержка из коробки**: Соответствие протоколу добавлено для строк, коллекций (`Array`, `Dictionary`, `Set`), буферов данных (`Data`), базовых чисел (`Int`, `UInt`, включая типы `128-bit` из iOS 18) и графических примитивов `CoreGraphics`.

## 🚀 Использование операторов

### 1. Безопасный инфиксный фоллбэк `~?`
Оператор `~?` проверяет левый операнд. Если он пустой (`isEmpty == true`), выполнение переходит к правому операнду. Поддерживает левоассоциативное связывание в цепочки.

```swift
import SwanCore

let cachedName = ""
let legacyName = "Старый Профиль"

// Если cachedName пустой, проверяется legacyName
let finalName = cachedName ~? legacyName ~? "Гость" 
print(finalName) // Выведет: "Старый Профиль"
```

### 2. Постфиксный безопасный анрэп `~!`
Оператор `~!` мягко разворачивает опциональный тип, соответствующий `Emptyable`. Если внутри лежит `nil`, он возвращает статическое пустое состояние типа (`.empty`), полностью предотвращая краш приложения.

```swift
// Работа со строками
let remoteTitle: String? = nil
print(remoteTitle~!) // Выведет: "" (вместо краша)

// Работа с коллекциями
let optionalUsers: [String]? = nil
for user in optionalUsers~! {
    // Безопасный цикл, который просто не выполнится для nil
}

// Работа с CoreGraphics
let customFrame: CGRect? = nil
let view = UIView(frame: customFrame~!) // Создастся с фреймом .zero
```

## 🛠 Реализация для собственных типов

Вы можете легко подписать любую свою структуру или класс под `Emptyable`, реализовав одно свойство и одну статическую переменную:

```swift
struct UserProfile: Emptyable {
    let id: UUID?
    let username: String
    
    // Критерий пустоты
    var isEmpty: Bool { id == nil }
    
    // Каноничное пустое состояние
    static var empty: UserProfile { 
        UserProfile(id: nil, username: "") 
    }
}

// Теперь операторы работают и для вашего типа:
let optionalProfile: UserProfile? = nil
let profile = optionalProfile~! // Вернет пустой профиль
```
