# Протокол Emptyable и операторы безопасного развертывания

Удобная надстройка, которая унифицирует проверку состояний и развертывание опционалов для стандартных типов, числовых скаляров и структур CoreGraphics, избавляя код от громоздкого бойлерплейта (`if-else`, `guard`).

Компонент `Emptyable` предоставляет единый контракт для типов данных, имеющих четко определенное «пустое» базовое состояние, а также вводит элегантные операторы-альтернативы системным механизмам принудительного развертывания.

## ✨ Ключевые особенности

* **Безопасность вместо крашей:** Постфиксный оператор `~!` заменяет опасный системный forced unwrap (`!`), возвращая дефолтное пустое значение типа вместо аварийного завершения приложения.
* **Строгая многопоточность:** Протокол явно наследуется от `Sendable`, гарантируя потокобезопасный перенос инстансов через границы изоляции в конкурентной среде Swift 6.
* **Универсальная автоматизация:** Поддержка протокола масштабируется на целые группы типов благодаря расширениям базовых протоколов `BinaryInteger` и `FloatingPoint`.

## 🚀 Использование операторов

### 1. Оператор динамического объединения `~?`
Инфиксный оператор `~?` проверяет левый операнд. Если свойство `isEmpty` левого операнда возвращает `true`, выполнение переходит к правому операнду. Оператор наследует приоритет `NilCoalescingPrecedence`, что позволяет безболезненно выстраивать цепочки фоллбэков.

```swift
import SwanCore

let cachedName = ""
let legacyName = "Старый Профиль"

// Если cachedName пустой, цепочка переключится на legacyName
let finalName = cachedName ~? legacyName ~? "Гость" 
print(finalName) // Выведет: "Старый Профиль"
```

### 2. Безопасный анрэп `~!`
Постфиксный оператор `~!` мягко разворачивает опциональный тип, соответствующий `Emptyable`. Если внутри контейнера лежит `nil`, оператор возвращает каноническое пустое состояние типа (`.empty`), гарантируя защиту от падений в рантайме.

Для ручного развертывания в стандартном синтаксическом стиле также доступно вычисляемое свойство `.orEmpty`.

```swift
// Работа со строками
let remoteTitle: String? = nil
print(remoteTitle~!) // Выведет пустую строку: ""

// Работа с числовыми скалярами и Double
let velocity: Double? = nil
let currentSpeed = velocity~! // Вернет 0.0 вместо краша

// Работа с коллекциями
let optionalUsers: [String]? = nil
for user in optionalUsers~! {
    // Безопасный цикл, который не выполнится для nil
}

// Работа с геометрическими структурами CoreGraphics
let customFrame: CGRect? = nil
let view = UIView(frame: customFrame~!) // Инициализируется с CGRect.zero
```

## 🛠 Матрица поддерживаемых типов

SwanCore предоставляет готовые соответствия протоколу `Emptyable` для следующих структур данных:

| Категория | Поддерживаемые типы | Критерий `isEmpty` | Значение `.empty` |
| :--- | :--- | :--- | :--- |
| **Коллекции** | `String`, `Array`, `Dictionary`, `Set`, `Data` | Количество элементов равно `0` | `""`, `[]`, `[:]`, `Data()` |
| **Целые числа** | Любые `BinaryInteger` (`Int`, `UInt`, `Int8`, `UInt64`, а также `Int128` / `UInt128` под iOS 18+) | Значение равно `.zero` (`0`) | `0` |
| **Числа с точкой** | Любые `FloatingPoint` (`Float`, `Double`, `CGFloat`) | Значение равно `.zero` (`0.0`) | `0.0` |
| **Векторы CoreGraphics** | `CGPoint`, `CGSize`, `CGRect` | Соответствие системным границам `.zero` | `.zero` |

> 💡 **Специфика CGRect:** При проверке пустоты для прямоугольников `CGRect` SwanCore уважает стандартную логику фреймворка `CoreGraphics`. Прямоугольник распознается как пустой, если хотя бы одно из его измерений (`width` или `height`) меньше или равно нулю.

## 🏗 Реализация для собственных типов

Вы можете легко подписать любую свою структуру или класс под `Emptyable`, реализовав критерий пустоты и статическую переменную по умолчанию:

```swift
import SwanCore

struct UserProfile: Emptyable {
    let id: UUID?
    let username: String
    
    // Критерий пустоты профиля
    var isEmpty: Bool { id == nil }
    
    // Каноничное пустое состояние по умолчанию
    static var empty: UserProfile { 
        UserProfile(id: nil, username: "") 
    }
}

// Теперь кастомные операторы работают и для вашего типа данных:
let optionalProfile: UserProfile? = nil
let profile = optionalProfile~! // Безопасно вернет пустой профиль
```
