# Протокол Costable и класс Cache

Универсальная, строго типизированная и потокобезопасная обертка над системным `NSCache`, поддерживающая любые типы Swift (`Sendable`) в качестве значений и автоматический подсчет «стоимости» ресурсов.

## 📋 Обзор

Класс `Cache` предоставляет современный Swift-интерфейс для эффективного хранения объектов и структур в оперативной памяти. Благодаря внутреннему контейнеру `ValueWrapper`, утилита полностью избавляет от ограничений старого `NSCache`: в качестве ключей можно использовать любые Swift-типы, реализующие `Hashable`, а в качестве значений — любые типы, соответствующие `Sendable` (`String`, `Array`, кастомные структуры, перечисления или классы).

## ✨ Ключевые особенности

* **Поддержка Value Types (структур):** Больше не нужно вручную оборачивать строки, массивы или словари в классы-адаптеры — обертка скрыта внутри реализации.
* **Реакция на давление памяти:** Автоматически сбрасывает данные при получении сигналов от ОС (Low Memory Warnings).
* **Swift 6 Concurrency:** Полное соответствие требованиям `Sendable`. Безопасность конкурентного доступа обеспечивается внутренними атомарными блокировками системного ядра.
* **Перехват вытеснения:** Позволяет передать `@Sendable` замыкание, которое сработает прямо перед тем, как элемент будет удален из памяти системой.

## 🛠 Кэширование с учетом стоимости ресурсов

Если сохраняемое значение реализует протокол `Costable`, утилита автоматически считывает его свойство `cost` при записи. Это позволяет гибко ограничивать кэш не только по количеству элементов (`countLimit`), но и по совокупному весу памяти (`totalCostLimit`), например, объему данных в байтах, используя встроенные расширения для `String`, `Array`, `Dictionary`, `Data` и `NSData`.

## 🚀 Пример использования

```swift
import SwanCore
import Foundation

// 1. Инициализируем кэш для структур (Ключ: UUID, Значение: Array)
// Благодаря расширению Array: Costable, вес кэша будет считаться автоматически в байтах!
let arrayCache = Cache<UUID, [String]> { evictedArray in
    print("Массив строк вытеснен из оперативной памяти. Элементов было: \(evictedArray.count)")
}

// Задаем лимит в байтах (например, ~100 Килобайт)
arrayCache.totalCostLimit = 100 * 1024 

// 2. Запись и чтение чистых Swift-структур без бойлерплейта
let sessionID = UUID()
arrayCache[sessionID] = ["SwanCore", "Cache", "Architecture", "2026"]

if let cachedStrings = arrayCache[sessionID] {
    print("Успешно извлечено из кэша: \(cachedStrings)")
}
```
