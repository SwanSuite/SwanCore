# Протокол Costable и класс Cache

Универсальная, строго типизированная и потокобезопасная обертка над `NSCache`, поддерживающая любые типы Swift со свойством `Sendable` в качестве значений и обеспечивающая автоматический расчет стоимости ресурсов.

## 📋 Обзор

Класс `Cache` предоставляет современный интерфейс на языке Swift для эффективного хранения данных в оперативной памяти. Благодаря внутреннему контейнеру `ValueWrapper`, компонент полностью устраняет ограничения устаревшего системного класса `NSCache`, требовавшего использования исключительно ссылочных типов. Он позволяет использовать любой стандартный тип Swift, соответствующий протоколу `Hashable`, в качестве ключа, и любой тип со свойством `Sendable` в качестве значения, включая чистые структуры (`String`, `Array`, `Dictionary`), перечисления (enums) и классы.

## ✨ Ключевые особенности

* **Поддержка типов значений (Value Types):** Устраняет необходимость вручную создавать объекты-обертки (boxing) для структур или коллекций. Инфраструктура контейнеризации полностью инкапсулирована внутри приватного слоя реализации.
* **Выселение данных при нехватке памяти:** Автоматически удаляет внутренние записи, когда операционная система генерирует уведомления о низком уровне свободной памяти.
* **Готовность к многопоточности Swift 6:** Полностью соответствует протоколу `Sendable`. Потокобезопасность для параллельных циклов чтения и записи гарантируется встроенной синхронизацией базовой платформы.
* **Перехват выселения данных:** Поддерживает опциональное потокобезопасное замыкание `@Sendable`, которое выполняется непосредственно перед тем, как элемент будет удален из кэша.

## 🛠 Кэширование с учетом стоимости ресурсов

Если кэшируемое значение соответствует протоколу `Costable`, подсистема автоматически извлекает его весовой коэффициент `cost` во время операции присваивания. Это позволяет ограничивать занимаемый контейнером объем памяти с помощью кумулятивных метрик (`totalCostLimit`), таких как размер в байтах. Компонент содержит готовые встроенные расширения для типов `String`, `Array`, `Dictionary`, `Data` и `NSData`.

## 🚀 Пример использования

```swift
import SwanCore
import Foundation

// 1. Настройка кэша для чистых структур Swift (Ключ: String, Значение: String)
// Соответствие String протоколу Costable гарантирует, что общая стоимость учитывает точное количество байт UTF-8.
let searchCache = Cache<String, String> { evictedQuery in
    print("Выселена строка поискового запроса объемом в байтах: \(evictedQuery.utf8.count)")
}

// Ограничение размера пула памяти (например, максимум 50 000 байт)
searchCache.totalCostLimit = 50_000

// 2. Операции записи и чтения без использования ссылочных оберток
searchCache["last_query"] = "Тяжелый строковый результат выполнения поискового запроса к базе данных..."

if let cachedPayload = searchCache["last_query"] {
    print("Извлеченное из кэша значение: \(cachedPayload)")
}
```
