# Расширение Bundle+Metadata

Набор вспомогательных свойств (хелперов) для класса `Bundle` из системного фреймворка `Foundation`, предоставляющий упрощенный интерфейс для извлечения метаданных и конфигурационных параметров из файла `Info.plist`.

## 📋 Обзор

Компонент инкапсулирует рутинную работу со словарем `infoDictionary` и системными ключами Core Foundation. Он предоставляет как статические свойства быстрого доступа для главного бандла приложения (`Bundle.main`), так и динамические свойства для конкретных экземпляров бандлов (например, бандлов встроенных динамических фреймворков или плагинов).

## ✨ Ключевые особенности

* **Безопасное разворачивание со значением по умолчанию:** Использование оператора нормализации `~!` (из подсистемы `Blankable`) гарантирует, что статические свойства всегда возвращают валидную строку `String` (при отсутствии ключа возвращается пустая строка `""`), исключая необходимость работы с `Optional` на вызывающей стороне.
* **Автоматический поиск локализованных имен:** Динамическое свойство `displayName` реализует логику каскадного поиска: сначала запрашивается пользовательское отображаемое имя (`CFBundleDisplayName`), а при его отсутствии происходит автоматический откат к базовому имени бандла (`CFBundleName`).
* **Инлайн-оптимизация (`@inlinable`):** Все вычисляемые свойства помечены атрибутом `@inlinable`, что позволяет компилятору Swift оптимизировать вызовы на этапе сборки приложения, устраняя накладные расходы на вызовы методов в рантайме.

---

## 📝 Спецификация маппинга ключей

Расширение сопоставляет свойства кода со строковыми ключами манифеста `Info.plist`:

| Свойство | Системный ключ `Info.plist` | Описание |
| :--- | :--- | :--- |
| `executable` | `kCFBundleExecutableKey` (`"CFBundleExecutable"`) | Имя исполняемого файла бандла. |
| `name` | `kCFBundleNameKey` (`"CFBundleName"`) | Краткое имя бандла (обычно совпадает с именем таргета). |
| `displayName` | `"CFBundleDisplayName"` *(с откатом к `name`)* | Локализованное или отображаемое имя приложения/модуля. |
| `shortVersion`| `"CFBundleShortVersionString"` | Маркетинговая (релизная) версия программного обеспечения. |
| `buildNumber` | `kCFBundleVersionKey` (`"CFBundleVersion"`) | Технический номер сборки (билд) для внутреннего трекинга. |

## 🚀 Примеры использования

### 1. Чтение метаданных текущего приложения (Статический интерфейс)
```swift
import SwanCore
import Foundation

// Извлечение имени и версии для отображения в UI (например, на экране "О программе")
let visibleName = Bundle.appDisplayName   // Например: "SwanKit Framework"
let currentVersion = Bundle.appVersion   // Например: "1.0.3"
let currentBuild = Bundle.appBuild       // Например: "42"

print("Запущено приложение: \(visibleName), версия: \(currentVersion) (\(currentBuild))")
```

### 2. Инспекция конкретного модуля (Динамический интерфейс)
```swift
// Получение бандла конкретного класса внутри динамического фреймворка
let frameworkBundle = Bundle(for: DetailViewController.self)

if let internalName = frameworkBundle.name {
    print("Имя бандла фреймворка: \(internalName)") // Например: "SwanCore"
}

if let marketingVersion = frameworkBundle.shortVersion {
    print("Версия фреймворка: \(marketingVersion)")
}
```
